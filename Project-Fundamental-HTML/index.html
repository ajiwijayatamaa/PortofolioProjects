BELAJAR HTML dan CSS

Tag yang Boleh Ada di <head>

  1. Judul Halaman <title>: Menentukan judul halaman browser

  2. CSS <style>: Menulis CSS langsung di halaman

  3. JavaScript <script>: Menambahkan JavaScript

  4. Metadata <meta>: Metadata ini penting untuk mendskripsikan website kita, contohnya:

    1. <meta charset="UTF-8">: charset singkatan dari Character set untuk menunjukan encoding karakter

    2. <meta name="description" content="Belajar HTML">: Deskripsi dari website kita

    3. <meta name="keywords" content="HTML,CSS,JavaScript">

    4. <meta name="author" content="Aji">: Pembuat nya siapa, ini penting untuk search engine agar dapat dengan mudah mengindentifikasi website kita

    5. <meta charset="UTF-8">: charset singkatan dari Character set untuk menunjukan encoding karakter

Tag yang Boleh Ada di <body>

  1. Teks: <h1>,<h2>,<h3>,<h4>,<h5>,<h6>,<p>, dll.

  2. Pendukung Teks: <br>,<hr>,<em>,<strong>, dll.

  3. Gambar: <img>.

  4. Hyperlink: <a>.

  5. List (bullets & numbering): <ul>,<ol>,<li>,<dl>,<dt>,<dd>.

  6. Tabel: <table>,<thead>,<tbody>,<tfooter>,<th>,<td><tr>, dll.

  7. Form: <form>,<input>,<select>,<button>, dll.

  8. Script: <script>.

  9. Object: <object>.

  10. Grouping: <div>,<span>.

  11. Komentar: <!-- -->.

Struktur Tag

<namatag atribut="nilai">

Contoh: <body bgcolor="red">

Atribut GlobaL

Tiap tiap tag punya atribut yang default atau yang global yang sama semua tag punya, kita sebut dengan atribut global, seperti:

  1. accesskey : Untuk menentukan elemen ini bisa diakses menggunakan keyboard atau shortcut
  2. class: Untuk menandai elemen
  3. id: Untuk menandai elemen
  4. dir: Untuk menentukan arah tulisannya / direction
  5. lang: language
  6. style: Untuk menyisipkan inline css
  7. tabindex: Untuk menentukan urutan form pas ktia pencet tab
  8. tittle: Untuk beri judul pada sebuah elemen

Praktek HTML

Belajar Image

src: URL atau path gambar yang akan ditampilkan yaitu Banner.png

alt: Teks alternatif jika gambar gagal dimuat juga dibaca oleh screen reader

title: Teks tooltip yang muncul saat kursor diarahkan ke gambar

width: Mengatur lebar tampilan gambar (dalam pixel) 250px walaupun tidak dituliskan px defaultnya itu px

CSS (Cascading Style Sheets)

CSS pada halaman ini ada beberapa kategori yang digunakan:

  1. embed:
